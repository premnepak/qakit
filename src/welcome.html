v1.0.6

Welcome to QAKit

Your all-in-one browser toolkit for QA engineers and developers. Here's everything that's new and improved since the last verified release.

What's new in 1.0.6
📡
Adobe DataLayer capture The Analytics tool now monitors adobeDataLayer (Adobe Client Data Layer) events under a new Adobe DataLayer category, including events fired during page load. Toggle it under Settings → Analytics Providers.
🗄
Session Storage support The Storage tool now has Local Storage / Session Storage tabs. Browse, search, edit, and delete sessionStorage keys for the current origin — with an optional Session Storage Keys filter in Settings.
🐞
Analytics tab reliability fix After the browser suspended the extension in the background, the Analytics tab could briefly show 0 events even though events had been captured. The event list now loads reliably every time.
🧭
JSON Viewer — Tree View scrolling fixed With large JSON, the Tree View tab clipped its content and showed no scrollbar. Tree View now scrolls smoothly regardless of document size.
🙏
Thank you This release was shaped by feedback from QAKit users — thank you to Jirong Han, Geoff Fry, Dev Kunwar, Manasa Esrapu, Hayley Schwartz, Yousef Leblanc, Naveen Saha, Ripon Das, Stacy Huerta, Harry Buckley, Bradford Ramos, Herman Chung, and Terry Lee for reporting issues and suggesting improvements.

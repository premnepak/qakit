1.0.4 May 2026 Released

✅Quality & reliability

  • Fully verified release — every feature introduced in 1.0.2 has been retested end-to-end against the published extension before this release. Where 1.0.3 was a straight resubmission, 1.0.4 is the version we're confident in.
  • Regression test suite — a comprehensive automated test suite covering the full extension has been built alongside this release. Every future update will be validated against it before shipping, so you can expect consistent, reliable behaviour as QAKit grows.

🛠Fixed

  • Markup editor — "Screenshot not found" error resolved — the ✎ Markup button was silently failing after the popup was closed and reopened. The screenshot was stored in the extension's service worker memory, which Chrome can unload at any time — causing the image to disappear before the Markup tab had a chance to read it. The fix uses chrome.storage.session, a browser-managed store that persists reliably for the lifetime of your browser session regardless of service worker restarts.

✨Polish

  • Various small refinements across the extension based on testing feedback gathered during the regression pass.
1.0.3 May 2026 Released

🔄Maintenance resubmission

  • Shortly after 1.0.2 went live on the Chrome Web Store, we identified issues that required the release to be pulled. 1.0.3 is the clean resubmission — same features as 1.0.2, no code changes. The underlying issues are addressed in 1.0.4.
1.0.2 May 2026 Released

✨New

  • Markup Annotation Editor — every screenshot toast now includes a ✎ Markup button. Click it to open the captured image in a full-screen editor with these tools:
    • Pen — freehand drawing
    • Rectangle — draw outlined boxes to highlight areas
    • Arrow — point to anything on the image
    • Highlight — semi-transparent marker overlay
    • Blur / Redact — Gaussian blur (size 1–10) or mosaic pixelation (size 11–20) to obscure sensitive information
    • Number markers — drop sequential numbered circles for step-by-step bug reports
    • Text — type labels directly onto the image
    • Select — move or resize any placed annotation; Delete key removes it
    • Crop — trim the image to a selected region
    Includes undo / redo, copy to clipboard, and Save (always opens the OS Save-As dialog so you choose where the PNG is written).

🛠Fixed & improved

  • Keyboard shortcuts now work out of the box — Region Screenshot is Ctrl+Shift+Z / Cmd+Shift+Z and Full Page Screenshot is Ctrl+Shift+F / Cmd+Shift+F. Both shortcuts are now registered as defaults in the manifest so they work immediately after install without needing manual configuration.
  • Ruler — keep multiple measurements on screen — the second click now locks the current measurement as a permanent teal line (with endpoint dots and a label). You can immediately start the next measurement. All locked lines stay visible until you press Esc.
  • Screenshot Save always shows a Save-As dialog — the ⬇ Save button in screenshot toasts now routes through the browser's download API, so the OS file-picker always appears regardless of Chrome's "Ask where to save" setting.
  • Time & Epoch — World Clock tab visible on first open — the World Clock sub-tab is now correctly highlighted and its panel shown when you first open the Time tool.

✨Polish

  • Best Locators pill is easier to read — the CSS / XPath / Playwright / Cypress switcher in the Element Inspector overlay now uses larger, clearly distinct buttons with framework logos and a dedicated active colour per framework (green / yellow / blue / purple) so the selected output style is unambiguous at a glance. Tooltips show the full framework name.
  • Inspector badge hint is clearer — the footer hint now reads "Click to pin · Esc to unpin / exit · Alt/⌥-click to drill in" instead of cryptic symbols.
1.0.1 May 2026 Released

✨New & improved

  • Smarter Best Test Locator — the Element Inspector now picks the most reliable selector for the element you hover over. It prefers, in order: an element's own test attribute (data-testid, data-cy, data-test, data-qa), its id, accessible attributes (aria-label, name, role), short visible text on links/buttons/labels, and finally a nearby ancestor's test attribute when nothing better is available.
  • Framework-aware copy output — switch between CSS, XPath, Playwright, and Cypress output styles in the inspector overlay. Copy emits a ready-to-paste line for your test framework:
    • Playwright → page.locator('…') / getByTestId('…') / getByRole('…')
    • Cypress → cy.get('…') / cy.contains(tag, text) (uses native Cypress chains — no plugins required)
    • Selenium-friendly XPath and CSS strings for any other runner
  • Right-click context menu copies — right-click any element on the page and pick QAKit → ⎘ Copy Best Test Locator, ⎘ Copy CSS Selector, ⎘ Copy XPath, or ⎘ Copy Outer HTML. Same logic as the inspector overlay, available without opening the popup.
  • Spacing Inspector gap distance — when hovering an element, the Spacing tool now shows the exact pixel gap between the element and its sibling neighbours, with cleaner labels that no longer overlap on tight layouts.
  • Robust XPath generation — XPath output uses exact class matches first, falls back to contains() for compound classes, and uses normalize-space() for text-based locators so they survive whitespace changes.

🛠Quality & reliability

  • End-to-end test suite added for the popup and inspector flows.
  • Inspector overlays remember your last-chosen output style between sessions.
  • Various small polish fixes across cookies, local storage, and page audit.
1.0.0 April 2026 Initial release

🚀First public release

  • Element Inspector with live tooltip showing tag, id, classes, test attributes, computed box model, and accessibility role.
  • Spacing Inspector — visualises margin and padding around any element.
  • Ruler for click-and-drag pixel measurements.
  • Responsive preview — Mobile / Tablet / Laptop / Desktop / Wide presets plus custom width.
  • Capture suite — Annotate, Region, Full Page, and Element screenshots, all delivered to the clipboard with a download toast.
  • Analytics monitor — captures GTM, GA4, DDL, Adobe, Tealium, Meta Pixel, Floodlight, Segment, and WAE events with rich search and filter.
  • Network Mock — intercept requests with wildcard URL patterns, custom JSON, status codes, redirects, blocks, and artificial latency.
  • Headers Modifier — add, override, or remove request and response headers.
  • Page Audit — performance, security, and accessibility scoring with Core Web Vitals and a persistent last-scan banner.
  • Session & environment tools — Environment Marker, Cookie Manager, Local Storage browser, and Console Errors capture.
  • Utilities — Time & Epoch, JWT / URL / Base64 encode-decode, Override Geolocation, Page Metadata extractor.
  • Developer tools — JSON Viewer with tree view and search, Text Compare with side-by-side diff and minimap.
  • Full keyboard shortcuts for Inspect, Spacing, Region, and Full Page screenshots.
  • Light / Dark themes, allowed-domains scoping, exportable settings.

🔒Privacy & security

  • Zero remote code execution — every script ships inside the extension.
  • Zero telemetry or analytics collected by the extension itself.
  • All permissions documented and justified in the published privacy policy.

Features
• Data tab — paste-only JSON input, validation
• Tree View tab — collapsible tree + Name/Value detail pane
• Search highlights matching keys/values, Next/Previous to cycle
• Expand all / Collapse all buttons
• Colour-coded by type (key, string, number, boolean, null)
• Resizable splitter between tree and detail panes

The attribute used for test IDs. Inspector will highlight this. Leave blank for auto-suggest.

Format used when copying locators from the right-click menu and as the inspector badge default. The badge has a per-session toggle to switch on the fly.

Comma-separated URL path prefixes. Console errors from these paths are captured. Defaults: /scripts/,/blocks/
